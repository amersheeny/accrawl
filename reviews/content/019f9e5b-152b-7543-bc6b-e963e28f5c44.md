# Content-strategist review

Run ID: `019f9e5b-152b-7543-bc6b-e963e28f5c44`

## Reviewed contexts

- A 401 response from companion account and transaction endpoints after a
  financial credential or its paired device loses authorization.
- A 401 response from companion push registration after the paired device
  loses authorization.

## Verdict

Use `access is no longer authorized` in both contexts.

The wording accurately describes authorization that was valid when the
request began but was revoked before the operation completed. It avoids
revealing which linked credential changed and gives both paths consistent,
non-enumerating language. Android behavior remains keyed to HTTP 401 and the
stable `access_revoked` response code, never to the prose.
