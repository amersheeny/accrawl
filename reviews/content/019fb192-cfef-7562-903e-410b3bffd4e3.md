## Verified model

Every authenticated user can add a private institution. Users see their own
private institutions and published copies for the current Accrawl workspace.
Platform operators can manage every private institution and publish a separate
copy without changing the private original. Users cannot edit published copies.
The interface must not expose administrator role terminology.

## Verdict

Use one badge per row because the three states are mutually exclusive. The
following exact strings were reviewed and APPROVED:

- `Published`
- `Private · yours`
- `Private · another user’s`
- `Publish a copy`
- `Publish a copy of {institution name}?`
- `This creates a separate published copy that everyone signed in to this Accrawl workspace can use. The original private institution remains private and unchanged. Other users cannot edit the published copy.`
- `Publish copy`
- `A copy of {institution name} is now published for everyone in this Accrawl workspace.`
- `Couldn’t publish a copy of {institution name}.`
- `This institution is already published.`
- `A published copy of {institution name} already exists in this Accrawl workspace.`

The strings retain the established product noun “institution”, introduce
“Accrawl workspace” only where the visibility boundary must be explicit, and
consistently distinguish publishing a separate copy from changing the private
original.
