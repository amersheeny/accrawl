# Content review: crawl request body

Run ID: `019fb3b8-781b-7771-ba81-85776dd9b26a`

Reviewer lens: product content strategist

Context: An API client sent request-body fields to either the crawl or refresh
endpoint. Crawling has no data-selection option and retrieves every supported
financial record for the connection. API authorization scopes and
organization-sharing scopes remain separate and unchanged.

Proposed copy:

> This request does not accept a body.

Verdict: revise.

Approved copy:

`Request body fields aren’t supported; a crawl or refresh retrieves all financial data supported for the connection.`

Rationale: This is specific, neutral, uses established product nouns, and
distinguishes unavailable data-selection options from the connection’s API
authorization scopes.
